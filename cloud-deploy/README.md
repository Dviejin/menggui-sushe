## 一、先看清这个服的压力画像（决定了能白嫖到什么程度）

| 维度 | 实测/估算 | 含义 |
|---|---|---|
| 运行时 | Node 原生 http，零第三方依赖 | 不用 `npm install`，部署 30 秒 |
| 内存常驻 | 约 35–50 MB | 512MB 小机器绰绰有余 |
| CPU | 单核 1% 以下 | 最低配 VPS 即可 |
| 流量 | 每房间约 2 KB/s（两人 × 2 次/秒轮询，报文几百字节） | 跑满一个月 < 5 GB，通常 < 1 GB |
| **致命约束 1** | **房间状态在进程内存里** | 进程重启 = 房间全丢，所以**必须常驻、禁止休眠** |
| **致命约束 2** | **必须单实例** | 多副本会把两个玩家分到不同节点导致互相看不见 |
| **致命约束 3** | 客户端已内置多候选地址探测 | 换服务器只要改链接，朋友无需任何配置 |

> 结论：**别用 Serverless / 云函数 / 会自动休眠的免费容器**。它们要么留不住内存房间，要么冷启动几秒会让对战卡顿。
> 你要的是"一台永远开着的、网速快的小机器"。

### 为什么不建议 Serverless（Vercel / Netlify / 云函数）
它们每次调用可能是不同实例、无请求即回收。`rooms` 这个内存对象会被清空，建房的人一刷新，朋友就进不去了。

## 三、我的推荐：分三条路，按你的情况挑

### 路线 A｜只想立刻和兄弟玩，越省事越好 —— **国内轻量 2核2G，约 68 元/年**
最划算的一档。理由：
- 一台真正属于你的机器，**24 小时不关机**，房间不会因为平台回收丢失；
- 国内节点延迟十来毫秒，放技能几乎无感；
- 用 **IP + 端口** 直接发微信群就能玩，**不需要买域名、不需要备案**；
- 300GB/月流量，你这游戏连 1% 都用不到；
- 折合每天两毛钱，比一杯奶茶便宜一年。

> 什么情况下才需要域名 + 备案？只有当你想把**微信小游戏版**（不是浏览器链接）也接上联机时才需要 —— 见下文第五节。

### 路线 B｜一分钱不想花 —— **Oracle Cloud Always Free（ARM 4核 24G，永久免费）**
- 真·永久免费，性能是 A 方案的十几倍；
- 门槛：需要一张 **Visa/Mastercard 实体信用卡**做身份核验（预授权 $1，几天后自动退回，不实际扣费）；
- 注册要点：关掉代理、用手机 4G/5G 热点，让 **IP 来源 = 信用卡发卡国 = 账单地址** 三者一致，成功率最高；
- 地域选**日本东京（Tokyo）或韩国春川（Chuncheon）**，别选热门的新加坡（容易没容量）；
- 抢占时需要反复重试 "Out of capacity"，也是它最劝退的地方；
- 延迟 40–90ms，玩《猛鬼宿舍》这种轮询同步的游戏**完全够用**；
- 注意：官方规定 ARM 实例长期闲置可能被回收，保持有服务在跑即可。

### 路线 C｜要正式做微信小游戏上线 —— **腾讯云 CloudBase / 微信云托管**
微信小程序/小游戏强制要求：request 域名必须 **HTTPS + ICP 备案**（不能有 IP、不能带端口，除非在控制台显式配置端口）。
微信自家云托管可以用 `callContainer` 绕过域名配置，CloudBase 提供的默认域名也是平台**已备案**的 —— 这是它相对自建的最大价值。

## 四、拿到机器后怎么装（三种方式任选）

### 方式 1：裸机一键脚本（推荐，最简单）
```bash
# 1. 把项目整个目录传到服务器
scp -r menggui-sushe root@<你的公网IP>:/root/

# 2. 登录并执行
ssh root@<你的公网IP>
cd menggui-sushe/cloud-deploy
chmod +x install.sh
sudo ./install.sh
```
脚本会自动：装 Node 22 → 部署到 `/opt/menggui-sushe` → 注册 systemd 服务（开机自启、崩溃重启）→ 放通防火墙 → 健康检查 → 打印分享链接。

之后更新游戏只需：
```bash
scp index.html root@<IP>:/opt/menggui-sushe/index.html
ssh root@<IP> "systemctl restart menggui"
```

### 方式 2：Docker（干净、易迁移）
```bash
docker compose up -d --build
```
> ⚠️ 务必保持 `replicas: 1`。多副本 = 房间分裂 = 联机失效。

### 方式 3：有域名想上 HTTPS
```bash
cp Caddyfile /etc/caddy/Caddyfile   # 先改里面的域名
systemctl reload caddy
```
同时在服务端设置 `FORCE_HTTPS=1`。

### 别忘了这一步：云平台安全组
腾讯云/阿里云控制台 → 防火墙/安全组 → 添加规则：**TCP 8080 允许 0.0.0.0/0**。
甲骨文还需要在 VCN → Security List 里加 Ingress 规则，并且 Linux 内部 `iptables` 常常默认拦全部入站：
```bash
sudo iptables -F        # 或按需只放行端口，详见各云文档
```

## 五、关于备案与 HTTPS（只有做小游戏才需要关心）

| 场景 | 需要什么 |
|---|---|
| 浏览器打开 H5 链接（微信群里转发链接） | **什么都不需要**，`http://IP:8080` 直接能玩 |
| 手机微信内置浏览器打开 http 链接 | 可以打开，可能会被提示"非官方页面"，能正常玩 |
| 微信小游戏正式版联网 | 必须：① ICP 备案域名 ② HTTPS 证书 ③ 微信后台配 request 合法域名 |
| 想去掉 http 的"不安全"提示 | 买个便宜域名（.top/.xyz 首年几元~十几元）+ Caddy 自动证书；**域名解析到国内服务器必须备案** |

> 省钱技巧：不想备案又要 HTTPS，可以把服务器选在**中国香港**（延迟 30–60ms），域名无需备案即可解析，配合 Cloudflare 或 Let's Encrypt 免费证书，总成本约 **25–40 元/月**。

## 六、运维小贴士

```bash
systemctl status menggui              # 看状态
journalctl -u menggui -f              # 看实时日志
systemctl restart menggui             # 重启（会清房间，挑没人的时候）
curl http://127.0.0.1:8080/api/ping   # 健康检查，返回 rooms 数量
```

已知限制：
- 房间存于内存，**服务器重启会丢失进行中的对局**（空闲 10 分钟也会自动清理）—— 玩家会看到"房间已失效"，重开一局即可；
- 若将来真要"重启不丢房间"，可以把房间落到 Redis，需要的话我再改一版；
- 建议把权衡后的链接放在收藏夹，随时 `net-test.js` 跑一遍验收：
  ```bash
  node net-test.js http://<你的公网IP>:8080
  ```
