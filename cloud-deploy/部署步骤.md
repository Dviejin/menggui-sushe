# 手把手：把《猛鬼宿舍联机版》搬到云服务器

> 全程大约 15 分钟，不需要懂 Linux，命令都是复制粘贴。
> 主线以**腾讯云轻量应用服务器**为例（推荐），末尾有阿里云 / Oracle 免费机的差异说明。

---

## 第 1 步 · 买一台服务器

1. 打开 <https://cloud.tencent.com/product/lighthouse> → 点 **立即购买**
2. 关键选项这样选（其他保持默认）：

   | 选项 | 怎么选 | 为什么 |
   |---|---|---|
   | 地域 | 离你和朋友最近的，如「广州」「上海」 | 延迟最低 |
   | 镜像 | **系统镜像 → Ubuntu Server 22.04 LTS** | 别选带宝塔/应用镜像的，越干净越省事 |
   | 套餐 | **2核2G 3M 带宽**（有新人专区 38 元/年更好） | 这游戏只要 40MB 内存 |
   | 时长 | 1 年 | 通常标注"续费同价"的款最划算 |

3. 购买完成后进 **控制台 → 轻量应用服务器**，记下那台机器的 **公网 IP**（形如 `123.45.67.89`）
4. 首次进入会要求设置登录方式 —— **直接设 root 密码**最简单（记牢它）

> 💡 这个游戏每条占用资源极端小：**内存约 40MB，跑满一个月流量不到 1GB**。
> 买更高配置纯粹浪费钱。

---

## 第 2 步 · 放行端口（最容易漏的一步）

轻量有**自己的防火墙**，跟 CVM 的安全组不是一回事，必须单独开：

进**实例详情 → 防火墙 → 添加规则**：

```
应用类型：自定义
协议：TCP
端口：8080
来源：全部 IPv4（0.0.0.0/0）
备注：猛鬼宿舍
```

> 忘了这步的表现是：**浏览器连不上、一直转圈**。

---

## 第 3 步 · 上传游戏 + 自动部署（三选一）

### 路线 A：Windows 本机一键推送（推荐，最快）

在你电脑上打开 **PowerShell**，切到项目目录运行一条命令：

```powershell
cd D:\1-微信文件\2026-10-09-14-12-01\menggui-sushe
.\cloud-deploy\deploy-from-windows.ps1 -Ip 你的公网IP
```

它会依次：SSH 连上去 → 上传 `index.html` / `server.js` / `install.sh` → 在服务器上自动装 Node、注册开机自启服务、放通端口、做健康检查 → **最后自动跑一遍联机验收测试**。

首次连接会问 `Are you sure you want to continue connecting`，输入 `yes` 回车；然后输入第 1 步设的 root 密码（输密码时屏幕不显示字符，正常，直接输完回车）。

> 想换端口：`-Port 9000`
> 只想更新不想测试：加 `-SkipTest`
> 后面每次改了游戏，**重跑同一条命令**就完成更新

### 路线 B：全程用浏览器，不装任何软件

1. 腾讯云控制台 → 实例 → **登录**（自带 WebShell，免密直连）
2. WebShell 右上角有**上传文件**按钮，把这三个文件传上去：
   - `index.html`
   - `server/server.js`
   - `cloud-deploy/install.sh`
3. 在 WebShell 里执行：

```bash
mkdir -p ~/ms/server ~/ms/cloud-deploy
# 假设上传到了 /root 目录
mv /root/index.html ~/ms/index.html
mv /root/server.js ~/ms/server/server.js
mv /root/install.sh ~/ms/cloud-deploy/install.sh
cd ~/ms/cloud-deploy && bash install.sh
```

### 路线 C：用 FinalShell / XShell 图形化拖拽

装个免费的 [FinalShell](https://www.hostbuf.com/)，新建 SSH 连接（主机填公网 IP，用户名 root，密码填第 1 步的），连上后左边有文件树，直接把三个文件拖进去，下面的命令行执行：

```bash
cd ~/ms/cloud-deploy 2>/dev/null || cd ~/menggui-sushe/cloud-deploy
bash install.sh
```

## 出错了怎么办

| 现象 | 大概率原因 | 处理 |
|---|---|---|
| PowerShell 说"找不到 ssh" | 系统没装 OpenSSH 客户端 | 设置 → 应用 → 可选功能 → 添加 **OpenSSH 客户端**；或改用路线 B/C |
| SSH 连接超时 | 公网 IP 写错 / 22 端口没开 | 检查 IP；腾讯云默认开放 22 |
| 浏览器打开一直转圈 | **8080 没放行**（最常见） | 回到第 2 步检查防火墙规则 |
| 页面能开，但显示"无法连接联机服务器" | 老版本页面缓存 | 强制刷新；确认用的是最新的 `index.html` |
| 部署脚本卡在装 Node | 服务器访问境外源慢 | 等一会儿，脚本会自动降级尝试三种装法 |
| 提示 `Address already in use` | 端口被占 | 换端口：`PORT=9000 bash install.sh` |
| 报错 `^M: bad interpreter` 或 `\r: command not found` | 文件被 Windows 编辑器改成 CRLF 换行 | 先执行 `sed -i 's/\r$//' install.sh` 再运行 |
| PowerShell 运行脚本提示一堆乱码 | 脚本丢了 UTF-8 BOM | 别用记事本另存为；直接用仓库里的原文件 |

查日志与重启：

```bash
systemctl status menggui            # 状态
journalctl -u menggui -f            # 实时日志（Ctrl+C 退出）
systemctl restart menggui           # 重启服务（会清空进行中的房间）
curl http://127.0.0.1:8080/api/ping # 本地健康检查，应返回 {"ok":true,"rooms":0}
```

## 以后怎么更新 / 日常维护

**改了游戏内容后**（比如调平衡、加道具）：重新跑第 3 步那条 PowerShell 命令即可，
新文件会覆盖旧文件并自动重启服务，朋友的链接不用变。

**服务器重启后**：服务会自动拉起来（`systemd` 已设开机自启），但**进行中的房间会丢**，
重开一局就好。空闲超过 10 分钟的房间系统也会自动清理。

**想把房间做成重启也不丢**：需要把内存里的房间落到 Redis，我可以改一版，说一声即可。

## 附录 · 其他平台的差异

**阿里云轻量服务器**：流程几乎一样，但第 2 步叫「**安全组 → 配置规则**」；初始用户名同样是 root。

**Oracle Cloud 永久免费 ARM（4核24G）**：
- 注册需 Visa / Mastercard 实体卡核验（预授权 $1 会退回）；**关掉代理、用手机热点**，让 IP / 发卡国 / 账单地址三者一致
- 地域选 **日本东京（Tokyo）或韩国春川（Chuncheon）**，别选新加坡（常常没容量）
- 开不了机提示 `Out of capacity` 是正常的，换可用域或隔几小时重试
- 额外两步：① VCN → Security List → 添加 Ingress 规则放通 8080；② 机器内部 `iptables` 默认拦全部入站，需执行 `sudo iptables -F`
- 延迟 40–90ms，玩这个游戏完全够

**已有任意 Linux 服务器**：直接跳到第 3 步。

**想上 HTTPS / 去掉"不安全"字样**：
需要域名。最省钱的玩法是域名（.top/.xyz 首年几块到十几块）+ Caddy 自动证书，
但**域名解析到中国大陆服务器必须 ICP 备案**（7–20 个工作日）。
不想备案的话，可以把服务器选在**中国香港**（延迟 30–60ms，免备案），
用本目录里的 `Caddyfile` 一条命令就能拿到免费证书。
只有要把**微信小游戏**（而非浏览器链接）正式上线时才必须用 HTTPS + 已备案域名。
